## 从这里开始

1. 先读深度学习手册第 1–4 页，弄清样本、标签、训练/验证/测试与独立分组。
2. 读第 5–8 页，理解小型 CNN 如何训练、输出什么、怎样评价。先跑通基础流程。
3. 学特征挖掘手册第 2–5 页，完成波形、频谱、包络和基础特征表。
4. 再学模型解释和对照实验；从普通 CNN 或 TFN 基线开始，再考虑 CS-SHAP。
5. FNO、超网络、元学习属于选学扩展，等有具体问题后再使用。

核心区别：**网络结构、学习方式、训练策略和泛化能力属于不同层次**。特征分析可以支持对模型判别依据的检验，不能单独证明模型或物理机理绝对正确。

## 使用边界

本资料是定向入门调研，不是穷尽式系统综述。复现难度为基于公开材料的估计，所有条目均标注“未运行验证”。“本次未确认官方代码”不等于作者没有代码。部分来源只核验了题录/摘要，相关限制逐条注明。

例子以机械振动、轴承诊断为主。向柴油机、齿轮或其他设备迁移时，需要重新确认传感器、故障机理、工况和标签；不能直接移植轴承特征频率。
