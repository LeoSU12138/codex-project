# 故障诊断深度学习方法详解与分类PDF

本目录是按需查阅的方法词典。先按[首页六步路线](../../README.md)确定当前问题：第3步查M01/M03，第4步查M32–M35，跨工况时查M20/M21；无需训练全部方法。

**[打开45页方法详解合订本](00_故障诊断深度学习方法详解_合订本.pdf)**。本手册为2026-11-01新增，独立于原三册入门资料；包含31项代表性建模/训练路线与4项事后解释方法，共35张方法卡。不是35种互斥网络，也不声称穷尽所有方法变体。

每张卡独立成页，详细讲解基本逻辑、输入与流程、核心表达、故障诊断示例、注意事项、验证与消融、特征挖掘着眼点和来源。合订本另有层级区分、术语、选型表、完整实验系统说明与参考阅读；PDF可搜索中文并用书签跳转。

## 来源与使用边界

本轮读取作者/官方项目说明和选定源码，补充通用方法教学；实际来源见[证据映射](../research-update-2026-11/来源与证据映射.md)。已有38篇工程题录保持原历史日期。通用时序预测或图像生成的资源不自动构成机械诊断效果证据；没有重新取得新论文全文，没有运行35种方法或比较性能。

修改方法时编辑方法详解.md和阅读与选型.md，再运行[src/build_research_update.py](../src/build_research_update.py)及[src/validate_research_update.py](../src/validate_research_update.py)。来源、索引、分页和实际验证记录需同步。
