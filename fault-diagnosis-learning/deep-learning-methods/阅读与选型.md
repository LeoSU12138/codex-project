# 怎样阅读这份方法手册

## 范围与阅读路线

这是一份面向机械故障诊断的代表性方法手册，覆盖31项建模/训练路线和4项冻结模型解释方法。一个方法卡可能同时介绍紧密相关变体；不是35种互斥网络，也不表示穷尽所有2026年新论文。各卡统一说明基本逻辑、输入与流程、核心表达、诊断示例、注意事项、验证消融和特征挖掘着眼点。

建议顺序：M01人工特征基线 → M03一维CNN → M05时频表征 → M32/M33低成本归因 → M34/M35频域与循环谱解释 → M20/M21跨工况协议。只有失败案例表明需要时，再选择长序列、无标签预训练、物理结构或大模型。

合订本与八个分册内容来自同一Markdown，不存在不同版本的算法卡。PDF可搜索中文，并提供章节书签；Markdown适合GitHub在线阅读。书中例子、公式和超参数是教学/设计说明，没有伪装成已执行实验。

## 先分清六个层级

| 层级 | 例子 | 回答的问题 |
| --- | --- | --- |
| 任务 | 闭集分类、异常检测、开放集、程度/RUL回归 | 要输出什么；标签与部署条件是什么 |
| 输入表征 | 原始波形、统计特征、频谱、时频图、图结构 | 把什么信息交给模型 |
| 网络结构 | MLP、CNN、RNN、Transformer、GNN、SSM | 怎样计算表示与预测 |
| 学习目标 | 监督、重构、对比、掩码、生成 | 用什么信号驱动参数更新 |
| 数据与部署协议 | 微调、域适应、域泛化、持续学习 | 哪些域、标签与时间信息可见 |
| 解释与验证 | Grad-CAM、IG、SHAP、干预、机理对照 | 模型依赖什么；解释是否可信 |

例如“CWT+ResNet+自监督预训练+域适应+SHAP”涉及多个层级。不能把整套系统的提升全归给ResNet，也不能把SHAP视为替代分类器。回归剩余寿命RUL需要退化轨迹、失效时间和按设备划分的专门协议，本手册以故障识别为主，不把RUL当普通分类改个输出即可完成。

## 通用符号与训练逻辑

B是批大小，C是传感器通道数，L是一个窗口点数，fs是采样率，K是类别数，d是表示维度。典型1D-CNN输入[B,C,L]，输出[B,K]。同样L在不同fs下代表不同物理时长L/fs，不能无条件沿用窗口配置。

logit是softmax前的类别分数，不是概率；softmax概率也未必经过校准。交叉熵CE推动真实标签对应输出，验证损失用于选择模型，测试集用于最终独立评价。训练模式与推理模式影响Dropout和BatchNorm。冻结参数后做梯度归因仍需要自动微分，不要误用全局no_grad。

感受野是一个输出位置能接触到的输入范围；嵌入/表示是编码器产生的向量；预训练是先用源任务或无标签目标学习；微调是再用目标训练信息更新。消融指只移除/替换一个假设因素，并维持其他条件可比。

物理一致性要求和可测机制相容；忠实度要求解释反映当前模型依赖；预测性能要求对独立样本有效。这三者分别评价，任何一项不能自动推导另两项。

## 依据实际问题选方法

| 观察到的问题 | 先做的低成本选择 | 满足条件后再尝试 | 首要检查 |
| --- | --- | --- | --- |
| 标签足、短稳态窗口 | 人工特征+线性/SVM，小1D-CNN | ResNet、多尺度或2D-CNN | 数据泄漏、工况混杂与容量公平 |
| 长周期关系重要 | 扩大物理窗口、TCN | LSTM、Transformer、Mamba | 长上下文真有增益、因果性与成本 |
| 标签少、无标签记录多 | 冻结特征线性探测 | 对比/掩码预训练、半监督 | 无标签来源、增强不破坏故障信息 |
| 仅健康资料较多 | 统计阈值/PCA、AE | VAE或复杂异常检测 | 正常工况覆盖、阈值与误报 |
| 工况变化 | source-only和明确域划分 | UDA或DG | 目标域可见性、负迁移 |
| 希望解释预测 | IG/Grad-CAM、合理干预 | SHAP/CS-SHAP | 目标、背景、粒度、随机化 |
| 先验明确且模型失效 | 固定机理特征 | 小波前端、联合滤波、PINN | 先验适用边界与结构消融 |
| 多传感器互补 | 单路与简单拼接 | 图或注意力融合 | 同步、图来源、缺失鲁棒性 |
| 部署算力有限 | 小模型与实测延迟 | 蒸馏、量化 | 漏报、校准、解释变化 |

不建议把GAN/扩散当默认数据扩增，也不建议把FNO/超网络/基础模型当默认分类起点。没有真实独立样本、可信方程或匹配任务时，增加复杂度无法补足证据。

## 一套完整可复现模型应保存什么

完整模型包括数据清单和划分、预处理、网络、损失、优化器、学习率与早停、随机种子、权重、类别映射、推理、评价、日志和依赖版本。只有网络类定义不能支持实验复现。恢复推理时要验证输入单位、采样率、通道顺序和标准化一致。

至少比较传统特征+浅层分类器、小型CNN和你选择的单一改进。统一训练/验证/测试、调参次数和数据增广；报告各类召回、macro-F1、独立单位、成本和失败样本。先按机器/记录分组再切片，避免重叠泄漏；标准化、特征筛选、解释背景和频带发现不得读取最终测试信息。

对比模型时保存每组结果与配对划分。窗口级准确率可以附报，但设备或记录才是实际独立单位时，不能按窗口数计算虚假精度。不需要为了文档学习先训练35套方法，应围绕一个问题选择2–3个有意义对照。

## 来源与证据边界

正式库D/F/C/S编号见原38篇科研论文库；“旧库”指43条基础学习资源；N是本轮工具/项目README，E是选定源码，B是补充基础实现入口。新的项目来源用于原理和接口导读，不能计成新增机械工程论文。书末列出相关题名、DOI/链接及核验类型。

本轮只读取定向来源，没有取得新论文全文，没有运行模型或证明方法排名。多数公式是标准方法的简化教学表达，实际实现需查原论文/版本；每张卡的诊断示例与建议实验由本仓库提出。方法更新快，正式写论文前仍要核验出版版本与近邻工作。
