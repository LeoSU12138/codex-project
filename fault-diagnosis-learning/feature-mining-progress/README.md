## 六类方向分别解决什么问题

| 方向 | 输入和主要输出 | 代表阅读编号 | 研究时需要检查什么 |
| --- | --- | --- | --- |
| 传统信号特征 | 波形→统计量、频谱、包络、候选解调频带或增强冲击 | S03、F02–F06、F12 | 先理解故障冲击、共振载频、调制频率、转速和噪声；检查带宽、周期、窗口及单位 |
| 自适应分解 | 混合信号→若干模态或候选冲击分量 | F07 VMD、F08 FMD、C08 | 检查模态数、滤波长度、参数敏感性和重构残差；一个模态不能仅凭高峭度命名为真实故障源 |
| 深度特征学习 | 波形/时频图→隐藏表示和故障类别 | D01、F01、D07 | 特征可用于分类不代表其物理含义清楚；先用独立分组和公平基线确认预测可靠性 |
| 可解释结构 | 信号→受约束的时频/小波前端→分类与可读中间量 | C01 TFN、C02、C03、C04、C11 | 需要修改模型；核参数或频率响应的含义不能直接推及全部后续层 |
| 事后解释 | 冻结模型、输入、目标输出和背景→重要时间片/频带/贡献图 | C10、C09、C06 CS-SHAP | 最贴近当前目标；检查解释是否忠实、是否稳定，以及背景与扰动有没有改变结论 |
| 工程先验与跨工况 | 信号和设备先验→跨工况预测、特征权重或机械事件关联 | D08、D09、F09–F11、C12；S04用于协议比较 | 区分仿真、台架、现场；明确目标域数据/标签可见性，并控制转速、负载和传感器混杂 |

这些路线可以组合。MCKD/MOMEDA通常承担信号增强；ClassBD（C07）将前端滤波与分类联合训练，不能直接当成对任意冻结模型的事后解释器。是否改结构，应由基线暴露的问题决定。

## 为什么优先研究“先训练、后解释”

对一个已经训练好的分类器，先固定权重、预处理、类别顺序和解释目标，例如“内圈故障logit”，再分析哪些时间片或频带影响这个输出。比较Grad-CAM与SHAP等方法时，要明确选用的卷积层、解释空间、上采样方式、背景样本和替换方式。CS-SHAP把关注点延伸到载频与调制频率，有助于和周期冲击机理对照，但仍需检查其变换、背景和近似设置。

一项研究应分开回答三个问题：

| 目标 | 需要的证据 | 不能仅靠什么下结论 |
| --- | --- | --- |
| 预测性能 | 锁定模型后，在独立设备/运行记录测试；混淆矩阵、各类召回率、macro-F1和错例 | 训练准确率、随机拆分重叠窗口得到的高分 |
| 解释忠实度 | 固定模型，比较重要/低重要/随机区域的合理干预；可增加参数随机化检查 | 热图好看、注意力值大或二维聚类分开 |
| 物理一致性 | 已知真值模拟、故障频率或阶次、机械事件对照，以及跨工况稳定性 | 某频带影响预测就推断其必然由故障造成 |

干预应尽量控制带宽、能量和处理方式，并观察重构信号是否合理；突然置零、切断频带或破坏相位可能制造分布外输入。模型分数下降也可能来自处理伪影。模型依赖、特征有用性和物理来源需要分别检验。

## 第一个实验如何落实

以下为执行方案，当前没有运行记录或性能结果。

1. **制作原始数据清单。** 每条独立记录至少包含设备、采集批次、工况、采样率、单位、传感器、故障标签和来源；同设备多条记录不自动成为独立设备样本。
2. **先按独立来源划分，再切片。** 根据研究目标按设备或运行记录分组。训练数据拟合标准化/特征筛选，验证集用于选模型与解释设置，测试集留到方案固定后。记录窗口长度、步长和物理时长。
3. **训练与保存基线。** 若没有模型，先使用公开数据建立简单特征分类器和小型1D-CNN。保存划分清单、随机种子、预处理参数、权重、类别映射、验证选模依据和错误样本。
4. **冻结模型做解释。** 先梯度或Grad-CAM，再按算力尝试SHAP/CS-SHAP；记录目标类别及logit/概率、层、背景来源、解释空间和样本抽取规则。冻结参数不等于禁止输入梯度。
5. **分别检验忠实度和机理。** 已知真值模拟用于检查定位；真实数据上做重要/低重要/随机区域干预，检查跨采集批次、工况、种子和背景的稳定性。模拟结果不能替代真实外部验证。
6. **把候选信息变成可测特征。** 例如预定频带能量或周期指标，在训练范围筛选，验证集选参；用相同划分、分类器和调参预算比较传统、随机和候选特征，最后统一独立测试。随机特征须匹配维度并重复抽取。这一步评价特征可用性，与固定模型的干预实验分开报告。

若研究故障程度趋势，必须有对应的程度标签，并控制转速、负载及传感器增益等混杂。柴油机应结合曲轴角、喷油、燃烧、气门事件；轴承故障频率公式不能直接套用于喷油器。
