
## 故障诊断深度学习

从一段振动信号，到一次有依据的故障判断

你现在没有现成模型，也可以开始学习。本手册以“用轴承振动判断正常、内圈故障、外圈故障”为贯穿例子，讲清楚一个监督式分类项目从哪里开始、每一步做什么，以及需要补哪些知识。

> 本课目标：这一课先掌握：样本和标签、训练与推理、训练集与测试集。暂时不要求你推导反向传播，也不要求你读懂 TFN 或 SHAP。

## 01  先看懂完整流程

你的第一个目标：完整说清楚数据怎样变成一个判断。

深度学习故障诊断，就是让一个可调参数的计算模型，通过带有已知状态标签的信号样本学习规律，再对新信号进行分类。标签来自实验记录、检查或其他可信依据，不是模型自己给出的标准答案。

- ① 明确任务并整理原始记录：确定设备、传感器、正常/故障类别；保留转速、负载、设备与采集批次。
- ② 按独立来源划分，再在各集合内切片：训练集学参数；验证集选方案；测试集留到方案确定后评估。
- ③ 训练与验证：用训练集确定标准化参数、训练模型；验证集使用同一变换，辅助选择模型。
- ④ 保留独立测试集：不参与训练或调参；最终使用已确定的预处理、模型和判定规则。
- ⑤ 保存完整推理所需信息：模型结构与权重、类别编号、预处理参数、输入设置。
- ⑥ 测试并检查错误：查看准确率、各类召回率和混淆矩阵；分析错判发生在哪里。
### 训练和推理，区别在哪里？

| 训练：让模型学习 | 推理：使用已经学好的模型 |
| --- | --- |
| 输入信号和已知标签，计算预测误差。 | 输入新的信号，得到类别分数和预测类别。 |
| 重复调整模型的权重和偏置。 | 通常不更新参数；不需要真实标签才能预测。 |
| 像做练习并根据答案订正。 | 像完成一道没有答案的新题。 |

解释与验证：模型训练完成后，可以再分析重要频率或冲击位置。解释是否合理和诊断是否准确，是两个需要分别检查的问题。


## 02  模型到底看见了什么？

先分清三个概念：采样点、样本、原始记录。

加速度传感器把机械振动变成随时间变化的数值。计算机读到的可能是一列数字，例如 0.12、-0.08、0.23……每个数字是某个采样时刻的测量值；物理单位由传感器标定与数据说明决定。

| 概念 | 通俗解释 | 本手册的教学例子 |
| --- | --- | --- |
| 采样点 | 某个时刻的一个测量值 | 某一时刻的振动加速度 |
| 原始记录 | 一次采集得到的完整连续信号 | 每条记录 5 秒，采样率 12,000 Hz |
| 样本 / 窗口 | 交给模型处理的一小段信号 | 每段 1,200 点，即 0.1 秒 |
| 标签 | 这段信号对应的已知状态 | 0=正常；1=内圈故障；2=外圈故障 |

> 只记住这个换算：样本时长 = 点数 ÷ 采样率 = 1,200 ÷ 12,000 = 0.1 秒。一条 5 秒记录有 60,000 点；不重叠地切分，可得到 50 个样本。

### 一条波形，本质是一串按顺序排列的数字

示意波形：仅用于解释数据形态，不代表某种真实故障，也不能凭这张图下诊断。

### 怎样打包给模型？

把一段信号记为 x，把它的标签记为 y。例如：x 是长度为 1,200 的数组，y 是数字 1。数字 1 只是“内圈故障”的编号，不表示故障比正常严重一倍。

若一次送入 32 段单通道信号，PyTorch 的一维卷积常用输入形状是 [32, 1, 1200]，分别表示“样本数、通道数、每段点数”。通道数为 1，表示只有一路输入信号。

关键提醒：从一条记录切出的 50 段，不等于做了 50 次独立实验。它们可能共享相同设备、工况和噪声特征。


## 03  数据划分比换网络更重要

学习类比：训练集是练习题，验证集是模拟题，测试集是最后的考试。

| 集合 | 用来做什么 | 不该用来做什么 |
| --- | --- | --- |
| 训练集 | 计算训练损失，更新模型参数。 | 代替独立测试来宣称泛化能力。 |
| 验证集 | 选学习率、训练轮数、模型版本和阈值。 | 在普通监督训练中用其标签更新权重。 |
| 测试集 | 方案固定后，评价对未参与开发数据的表现。 | 反复查看结果，继续挑模型、选特征。 |

### 最常见的陷阱：把同一条记录切碎后随机混分

假设两个窗口有一半采样点重叠，一个进训练集，一个进测试集，模型就可能在考试时遇到几乎见过的题。即使窗口不重叠，来自同一设备或同一次采集，也仍可能非常相似。

> 先决定你想证明哪种泛化能力：先按设备、试验批次或完整采集记录分组，再在各组内部切片。如果目标是“新设备也能用”，同一设备的记录要放在同一集合；如果目标是“新工况也能用”，需要单独设计工况外测试。

### 预处理：让输入一致，但保留有用信息

① 检查缺失、异常长度、单位和采样率；核对传感器位置/标定、饱和削顶、掉点与转速/负载记录。② 按固定长度切片。③ 根据任务做去均值或标准化。④ 如果确有需要，再考虑滤波和降噪；不要一上来把所有处理都叠加。

若采用全局标准化，可把每个值减去训练集均值，再除以训练集标准差。验证集、测试集和新数据都使用这组已保存的参数；不能先用全部数据计算参数。[2]

逐段标准化是另一种选择，但会削弱段与段之间的幅值差异。如果幅值变化正是故障严重程度的重要信息，就要谨慎使用，并保留原始数据。

常见的 60%/20%/20% 只是比例示例。独立来源数量、类别覆盖和预期使用场景，比凑比例重要。没有足够独立记录时，应如实说明实验的适用范围。[3]


## 04  CNN 怎样把信号变成类别？

CNN：卷积神经网络。先把它理解成“可学习的局部模式检测器”。

卷积核是一小组可调数字。它沿信号滑动，对局部数据做加权计算；每滑到一个位置，就输出一个响应。多个卷积核可以对不同的局部形状产生不同响应，但它们并非天然对应某种故障。

| 层 / 模块 | 做什么 | 可以怎样理解 |
| --- | --- | --- |
| 一维卷积 Conv1d | 从局部信号中计算多个响应序列。 | 拿多个小探头沿波形扫描。 |
| 激活函数，例如 ReLU | 引入非线性；ReLU 把负响应置零。 | 让网络能组合更复杂的模式。 |
| 池化 / 汇总 | 压缩长度或汇总信息。 | 把局部观察整理成简要描述。 |
| 全连接分类层 | 把特征组合成各类分数。 | 根据多个线索做综合判断。 |

### 看一个具体的尺寸变化

例如：输入 [32, 1, 1200]；第一层使用 8 个长度为 9 的卷积核，步长为 1，两端各补 4 个零，得到 [32, 8, 1200]。这时每个样本有 8 条特征响应序列。

之后可沿时间维取平均，得到每个样本的 8 个特征，即 [32, 8]；分类层再输出 [32, 3]，对应 3 个类别分数。这是讲解结构用的极简例子，不保证对具体数据效果最好。

> 区分分数、概率和类别：某个样本的概率型输出可为：[0.10, 0.75, 0.15]。若类别顺序是正常、内圈故障、外圈故障，选最大值便得到“内圈故障”。这些数值只是示例；0.75 不保证实际正确率就是 75%。

分类层常先输出原始分数，称为 logit。Softmax 将多个分数转换为和为 1 的概率型数值。预测类别通常取最大值；概率是否可信，还涉及后续的校准问题。

“特征图”是卷积层的响应，“类别分数”是最终判断依据之一，“真实故障分量”是物理信号中的组成部分。三者不是同一个东西。


## 05  训练到底在改变什么？

训练改变的是权重和偏置；输入标签通常保持不变。

模型开始时的参数一般由初始化规则生成，还没有学会区分故障。训练使用已知标签，反复检查预测与答案的差距，再调整参数。[1,4]

| 一次训练更新 | 发生的事情 |
| --- | --- |
| 1. 取一个批次 | 例如取 32 段信号，以及它们的 32 个标签。 |
| 2. 前向计算 | 输入信号经过网络，得到各个类别的分数。 |
| 3. 计算损失 loss | 用损失函数衡量预测与真实标签的不匹配程度。 |
| 4. 反向传播 | 计算损失对每个可训练参数的梯度。 |
| 5. 优化器更新 | 根据梯度和学习率调整参数，例如用 Adam 或 SGD。 |
| 6. 继续下一批 | 重复上述过程；通常先清除上一批累计的梯度。 |

可以把梯度想成“参数朝哪个方向微调，可能使损失下降”的提示。学习率控制每一步改动的尺度。参数太多或学习率过大，都可能让学习变得不稳定。

### 三个词：batch、epoch、学习率

batch 是一次更新所用的一批样本。epoch 是完整遍历一遍训练集。学习率是更新步长的控制量。例如训练集有 900 段，batch=32，保留最后不足一批的数据，则每轮有 29 次更新。

卷积核权重属于“模型参数”，由训练学习；学习率、卷积核长度和 batch 大小属于“超参数”，由你设定并参考验证集选择。验证阶段通常不做梯度更新。

### 训练结束后，你究竟得到什么？

核心产物是模型结构及其已学习参数，常保存为检查点；还要保存类别映射、标准化参数、输入长度与采样设置。损失曲线、预测结果和特征图是分析材料，不等于模型本身。[5]

入门实现提示：PyTorch 的 CrossEntropyLoss 通常直接接收 logits；不要先手动 Softmax 再把结果交给它。这一点到写代码时再练习。[4]


## 06  怎样判断模型真的学会了？

只看训练准确率，无法知道模型能否处理新的数据。

下面是一份人为构造的二分类结果，只用于学习指标。把“故障”当作需要检出的正类。行是真实类别，列是预测类别。[6]

| 真实状态 / 预测结果 | 预测正常 | 预测故障 |
| --- | --- | --- |
| 真实正常：80 个 | 76：正确排除 | 4：误报 |
| 真实故障：20 个 | 5：漏报 | 15：正确检出 |

| 指标 | 怎么算 | 在这个例子中 |
| --- | --- | --- |
| 准确率 Accuracy | 所有样本中，判断正确的比例。 | (76+15)/100 = 91% |
| 故障召回率 Recall | 真实故障中，有多少被检出。 | 15/20 = 75% |
| 故障精确率 Precision | 报为故障的样本中，有多少确实故障。 | 15/(15+4) ≈ 78.9% |
| F1 | Precision与Recall的调和平均。 | 2×15/(2×15+4+5) ≈ 76.9% |

虽然总准确率有 91%，仍漏掉了四分之一的故障。类别不平衡时更不能只看准确率：若 100 段中有 99 段正常，全部猜正常也有 99% 准确率，却一个故障都检不出来。

### 学会观察三种现象

欠拟合：训练和验证表现都差，可能是模型、输入处理、标签或训练设置不合适。过拟合：训练越来越好，验证停滞或变差，模型可能记住了训练数据的偶然细节。数据泄漏：测试表现异常好，原因可能是见过近似样本或使用了测试信息。

> 第一个实验的结果清单：至少保留：训练/验证曲线、测试混淆矩阵、各类召回率、数据划分说明、错误样本。以后做论文，还要看不同随机种子、不同设备或工况下的稳定性。

划分在哪个层级，结论就受哪个层级约束。来自少量记录的许多窗口，不应被当成大量独立试验来夸大证据。新类别出现时，普通分类器也可能自信地分错。


## 07  用一个完整例子串起来

任务：由一段振动信号判断正常、内圈故障或外圈故障。

假设你拥有 30 条相互独立采集的记录，三类各 10 条；每条 5 秒，单通道，采样率 12,000 Hz。这里的数量用于演示流程，不代表公开数据集恰好具有这些独立记录。

| 步骤 | 具体操作 | 得到什么 |
| --- | --- | --- |
| 任务与标签 | 固定 0=正常、1=内圈故障、2=外圈故障。 | 类别映射表 |
| 按记录划分 | 每类 6 条训练、2 条验证、2 条测试。 | 18 / 6 / 6 条记录 |
| 各集合内部切片 | 每段 1,200 点，不重叠，每条记录得 50 段。 | 900 / 300 / 300 个样本 |
| 预处理 | 例如只用训练集估计全局均值和标准差。 | 同一套变换参数 |
| 建立基线 | 先做简单统计特征分类器，再训练小型 1D-CNN。 | 可比较的基本方案 |
| 训练与选择 | 用训练集学习；根据验证表现选检查点。 | 冻结的模型版本 |
| 独立测试 | 用 300 段测试样本输出预测，汇总错误。 | 混淆矩阵与各类指标 |
| 后续解释 | 分析模型依赖的频带与信号位置。 | 待物理验证的候选特征 |

> 把“训练一次”和“预测一次”分开：训练结束后，一条新的 1,200 点信号，经相同预处理送入模型，就可以得到一个类别判断。不需要每来一条新信号，就重新训练一次。

公平比较：简单基线和深度网络应使用相同的独立数据划分。基线可以先提取均方根、峰值等统计量，再用简单分类器；如果深度网络没有带来改善，就应检查数据、任务或模型设置。

边界：这份记录级划分不自动证明模型能识别“从未见过的新轴承”。若同一物理轴承贡献多条记录，应按轴承身份分组。窗口 0.1 秒也只是演示值，实际要覆盖足够的故障周期。


## 08  需要学的知识清单

不必先把高等数学、信号处理和全部神经网络课程学完。

| 知识模块 | 先学这些 | 达到这个程度即可继续 |
| --- | --- | --- |
| Python 与数组 | 变量、循环、函数；NumPy 数组、切片和 shape。 | 能读取数组、截取 1,200 点并检查长度。 |
| 画图与文件 | 路径、CSV/MAT 文件；折线图、坐标和单位。 | 能画一段信号，不把采样点编号当秒。 |
| 信号基础 | 采样率、时长、幅值；转速与频率；FFT 的作用。 | 能说明“什么时候变化”和“哪些频率变化”。 |
| 机械基础 | 轴承或齿轮的部件、故障类型、激励与传递路径。 | 知道标签代表什么，不把所有振动都当故障。 |
| 数学最低准备 | 向量和矩阵、加权和、平均与标准差、导数直觉。 | 能理解数据形状、标准化和梯度方向。 |
| 机器学习基础 | 样本、标签、训练/验证/测试、分类、过拟合。 | 能解释为什么测试集不能用于调参。 |
| 深度学习基础 | 卷积、激活、池化、损失、梯度、学习率。 | 能口述一次训练更新，知道权重如何改变。 |
| PyTorch 操作 | Tensor、Dataset、DataLoader、训练/评价模式、保存。 | 能跑通一个小型分类网络并重新加载预测。 |
| 评价与实验 | 混淆矩阵、召回率、分组划分、简单基线、复现记录。 | 能看懂失败案例，而不只报告最高准确率。 |

### 哪些内容可以稍后再学？

进入特征挖掘后，再系统学习包络分析、STFT、小波、卷积核频响、Grad-CAM、SHAP，以及解释结果的扰动验证。Transformer、复杂网络融合、完整反向传播推导，不是当前第一道门槛。

优先级：先理解数据和评价，再学小网络；先跑通一个完整流程，再加复杂模块。你已有 Python / MATLAB 基础时，可把更多精力放在信号、划分和训练逻辑上。


## 09  按这个顺序学习与过关

按成果推进；不把固定天数当作必须完成的期限。

| 阶段 | 要完成的小任务 | 可以进入下一步的标志 |
| --- | --- | --- |
| A  看懂一段信号 | 读取一条记录；画时域图；计算它的时长。 | 知道每一轴和单位，能区分点、窗口、记录。 |
| B  看懂频率 | 构造一个正弦信号；改变频率；观察 FFT。 | 能说清波形变密和频谱峰移动之间的关系。 |
| C  组织数据 | 建立文件清单、标签和组编号；划分后切片。 | 能说明某条测试记录为何没在训练中出现。 |
| D  训练小模型 | 学习简单基线与 1D-CNN；观察损失变化。 | 理解输入形状、输出类别和参数更新。 |
| E  独立评价 | 加载选定模型；画混淆矩阵；查看错判。 | 能说明模型漏检哪一类，以及结论的范围。 |
| F  开始解释 | 冻结模型；分析重要频带，再核查物理含义。 | 把模型重要性与物理故障来源区分开。 |

### 工具各自负责什么？

NumPy：组织和计算数组。Matplotlib：画信号和结果。SciPy：读取部分科学数据格式、FFT 和信号处理。scikit-learn：基线模型、数据划分和指标。PyTorch：构建、训练和保存神经网络。

### 电脑准备到什么程度就够了？

入门小实验可以先使用 CPU，运行速度取决于样本量和网络大小；无需先为 CUDA 问题停下学习。建议为项目创建独立 Conda 环境，保留依赖版本；若现有环境已经能用，先验证基本导入与小样本训练即可。

> 今天的起点：当前最值得做的小任务：任选一段有采样率说明的振动记录，回答“它有多少点、多少秒、是什么状态、来自哪次采集”。先完成这个任务，再开始调网络。


## 10  它怎样接上你的特征挖掘？

目标：知道模型判断正确时，究竟利用了什么信息。

你希望先有一个能诊断的模型，再挖掘其所学特征，并用这些特征检验判断依据是否合理。基础分类流程跑通以后，就能进入这个阶段。

| 层次 | 实际回答的问题 | 常见输出 |
| --- | --- | --- |
| 诊断结果 | 这段信号属于哪个状态？ | 预测类别和类别分数 |
| 模型解释 | 什么输入或内部响应影响了判断？ | 重要时间片、频带、通道或原型 |
| 信号提取 | 能否从混合信号保留候选相关成分？ | 重构波形、包络或频谱 |
| 物理验证 | 这些成分是否与故障机理和独立试验一致？ | 特征频率、阶次、工况与严重度趋势 |

### 一个以后可以做的解释实验

冻结训练好的模型，记录它对某个样本的故障分数；再抑制一段频带，观察分数是否改变。如果明显下降，只能先说“模型依赖这段频带”。要继续与随机频带、其他解释方法和物理规律对照。

人为删频带会改变信号分布，因此分数变化并不自动证明该频带就是故障源。若你依据解释结果筛选特征，应在训练/验证阶段确定规则，再使用未参与选择的数据检验。

> 研究中需要保留的三个区别：诊断准确 ≠ 判断依据一定正确。模型认为重要 ≠ 该成分必定由故障产生。发现合理频带，也不等于已经分离出唯一的物理故障源。

### 怎样使用前面推荐的 TFN？

等你能说清输入、标签、训练与测试后，再读 TFN：先看它如何完成分类，再看可学习时频卷积层怎样支持频带解释。作者提供模型代码和 CWRU 训练流程，可作为后续练习入口。[9]

轴承数据适合练习流程。转向柴油机时，还要考虑燃烧冲击、曲轴角度、转速与负载等因素，不能把轴承的故障特征频率直接套到喷油嘴故障上。

### 六个问题

1. 一条 12,000 Hz 采样的信号有 60,000 点，它持续多久？2. 每 1,200 点构成一个样本，单样本时长是多少？不重叠能切几段？3. 训练时主要改变原始信号、标签，还是模型参数？4. 为什么不能把高度重叠的相邻窗口随意分到训练集和测试集？5. 模型输出 [0.10, 0.75, 0.15]，类别顺序为正常、内圈、外圈，预测是哪类？6. 准确率很高，但所有故障都被判断为正常，模型有用吗？应查看什么指标？

## 13  把名词放回正确的位置

人工智能包含机器学习；深度学习是以多层可学习表示为核心的一类机器学习。

不要把所有名词放进同一个“算法排行榜”。一个项目可以同时是：用CNN结构、做自监督预训练、再用监督标签微调、最后在未知转速上评估泛化。这些描述互相补充。[D01,D05,D06]

| 层次 | 回答的问题 | 常见概念 |
| --- | --- | --- |
| 任务 | 要预测什么？ | 故障分类、异常检测、故障定位、程度回归、剩余寿命预测 |
| 输入表示 | 数据如何呈现？ | 原始波形、幅值谱、包络谱、时频图、人工特征 |
| 网络结构 | 如何计算？ | MLP、CNN、RNN/LSTM、Transformer、自编码器、GNN |
| 特殊建模 | 怎样引入算子或条件？ | 神经算子/FNO、超网络、物理信息方法 |
| 学习方式 | 答案从哪里来？ | 监督、半监督、自监督、无监督；强化学习另有决策目标 |
| 训练策略 | 怎样学得更好？ | 迁移、微调、多任务、元学习、数据增强、正则化 |
| 约束与解释 | 为何这样判断？ | 物理约束、可解释结构、SHAP、IG、频带遮蔽 |
| 评价能力 | 换数据还行吗？ | 同分布泛化、跨工况/设备泛化、鲁棒性、校准 |

> FNO：神经算子的一种结构。超网络：生成另一个网络权重的机制。泛化：模型在新数据上的表现。三者不能作为同一层面的同义词。


## 14  常用网络怎样选择

先建立小模型基线，再根据明确的数据问题增加复杂度。

| 结构 | 通俗理解与用途 | 主要注意点 |
| --- | --- | --- |
| MLP | 将一组数逐层组合；适合人工特征表。 | 不直接利用波形的局部平移结构。 |
| 1D CNN / TCN | 短滤波器沿时间滑动；TCN常结合扩张卷积覆盖更长历史。 | 感受野须覆盖相关周期；在线任务检查是否用了未来点。 |
| 2D CNN | 从时频图学习局部纹理。 | 画图参数是方法的一部分；坐标与色标不能混乱。 |
| RNN / LSTM / GRU | 逐步更新状态，处理序列依赖。 | 长序列训练成本、梯度和状态重置要检查。 |
| Transformer | 让不同时间片交换信息。 | 数据量、注意力成本、切块和位置编码。 |
| GNN | 在传感器或部件连接图上聚合信息。 | 图的边必须有依据；随意建图可能增加伪关系。 |
| Autoencoder | 先压缩，再重构输入；可学表示或做异常检测。 | 重构好不等于分类好；正常模型也可能重构故障。 |
| GAN / VAE / 扩散模型 | 学习数据分布，可用于生成或去噪。 | 合成数据不能代替真实独立测试；警惕标签失真。 |

ResNet的残差连接让模块学习“在原输入上增加什么”，可嵌入CNN等网络。Attention是一类信息加权机制，Transformer是一种使用该机制的架构。[D09,D10]


## 15  学习方式与训练策略

目标不同，即使使用同样的CNN，训练任务也可能完全不同。

| 方式 | 故障诊断中的例子 | 你必须说明什么 |
| --- | --- | --- |
| 监督学习 | 每段波形有正常/故障标签，训练分类。 | 标签来源、误标风险、每类独立设备数。 |
| 无监督/单类检测 | 主要用正常数据学习规律，异常分数超阈值报警。 | 异常不一定是已知故障；阈值怎样确定。 |
| 自监督学习 | 遮住一段信号让模型重建，或拉近同一信号的两种增强表示。 | 预训练数据来源；增强是否保留故障信息。 |
| 半监督学习 | 少量有标签样本加大量无标签样本。 | 伪标签错误如何控制，是否偷用了测试数据。 |
| 迁移/微调 | 在设备A上预训练，再用设备B的训练样本调整。 | 目标设备可用多少数据和标签。 |
| 多任务学习 | 同时预测故障类别和转速。 | 辅助任务是否改善主任务，损失权重如何选择。 |

### 几个常被混淆的词

“自监督”通常从数据自身构造训练目标，并不等于完全无需设计标签逻辑。“端到端”表示优化可以从输入贯通到输出，不代表不需要数据清理。“物理信息”可以进入输入、结构或损失；经典PINN常用方程残差，但不是所有物理启发网络都属于这种形式。[D14]

> 新手第一条路线：监督分类 + 原始波形 + 小型1D CNN。标签不足、工况变化等问题出现后，再学习对应策略。


## 16  傅里叶神经算子是什么

先懂FFT，再理解“算子”为什么不是普通分类器的同义词。[D11,D13]

普通分类网络把一段波形映射到几个类别分数。算子学习关注“一个函数到另一个函数”的映射，例如把某个材料参数场映射到对应的位移场。计算时函数被采样成数组，但希望学到的规律不只依赖某个固定网格。

### 一个Fourier层做什么？

| 步骤 | 直观意义 |
| --- | --- |
| 输入特征 → Fourier变换 | 把当前特征转换到频域。 |
| 对保留的频率模态做可学习变换 | 学习不同特征通道之间怎样组合；通常只保留部分模态。 |
| 逆Fourier变换 | 回到空间或时间坐标。 |
| 与逐点线性分支相加，再做非线性变换 | 补充局部通道信息；多层组合形成复杂映射。 |

### 它和FFT + CNN有什么不同？

FFT是一种确定的数学变换，不会因为训练而改变。把频谱交给普通CNN，是选择了频域输入。FNO把可学习的频域运算作为网络内部的算子层；还涉及输入函数、坐标、输出函数和采样网格的定义。

> 对故障分类可以尝试FNO编码器再接分类头，但这属于新的任务设计。原论文在PDE上的结果不能直接证明它优于轴承CNN。

迁移分辨率时要检查：物理区间、坐标单位、采样率、可解析频段、归一化和训练分布是否一致。网格兼容性不等于任意分辨率都保持精度。若故障线索在高频，截断模态也可能丢失信息。


## 17  超网络、元学习和泛化

超网络生成权重；元学习组织学习任务；泛化要靠实验检验。[D12,D17]

设主网络为 f，输入振动为 x。普通网络训练后使用一组固定权重。超网络 h 接收条件 c，输出主网络所需的部分或全部权重：θ = h(c)，再计算预测 f(x; θ)。超网络本身的参数也需要训练。

> 教学例子：c包含转速和负载。超网络根据工况调整某个滤波层，主网络再完成故障分类。这只是可能的设计，不是已经验证有效的方案。

| 概念 | 实际含义 | 不是自动得到的能力 |
| --- | --- | --- |
| 超网络 | 一个网络生成另一个网络的权重。 | 不自动保证未知工况泛化。 |
| 超参数优化 | 搜索学习率、层数、损失权重等配置。 | 不是生成主网络权重的超网络。 |
| 超图神经网络 | 在可连接多个节点的超边上学习。 | 与HyperNetworks是不同概念。 |
| 元学习 / MAML | 在许多任务上学习易于少样本适应的初始化等。 | 不等于没有新样本就能识别任何故障。 |

### 条件变量最容易出问题

推理时必须能获得c，不能偷偷使用真实故障标签。只有设备编号的嵌入，未必能处理从未见过的编号。转速范围外的外推也可能失败；应与“把工况直接拼到普通网络输入”等更简单方案比较。

前置知识：先懂普通网络权重、矩阵形状和反向传播，再学条件化参数。生成大量权重会增加内存开销，先从小模块开始，检查梯度和条件扰动稳定性。只有固定工况或独立数据很少时，不宜直接套超网络。


## 18  泛化到底怎样检验

先写清“新”指什么，再选择数据划分。[D04,D08,D15,D16]

| 声称的能力 | 需要怎样测试 | 常见偷换 |
| --- | --- | --- |
| 同工况新记录 | 相同采集条件，不同独立记录或试验。 | 相邻重叠窗口随机分组。 |
| 跨轴承/设备 | 测试轴承或设备不参与训练和选择。 | 同一轴承换文件名当新设备。 |
| 跨转速/负载 | 整个目标工况保留为外部测试；源域内选模型。 | 用目标测试标签调参后说泛化。 |
| 抗噪声 | 事先定义噪声类型和信噪比；评估多种强度。 | 只加白噪声就称适应所有现场噪声。 |
| 未知故障识别 | 训练中没有该故障；另设拒识与开放集评价。 | 闭集softmax最高类别就是未知诊断。 |

### 域适应与域泛化

域适应训练可见目标数据，例如DANN使用无标签目标样本；域泛化训练不可见目标域。小样本适应通常给新任务少量有标签支持样本，查询集标签仅供评价，二者按独立来源分开。元学习在源任务训练，在新任务按约定适应。测试时适应须另说明更新和信息可见性。

### 重复实验也有层次

不同随机种子能反映训练波动；独立轴承、设备或试验重复才能支持更广泛的外推。几千个相邻窗口不能算成几千次独立实验。报告每类召回率、macro-F1及分组结果；置信区间应按独立组计算。

> 泛化是一个有边界的结论：在什么设备、哪些工况、怎样划分和多少独立重复下成立。


## 19  一个完整模型需要什么

网络结构只是其中一部分；完整项目要让别人能重新得到预测。

| 组成 | 至少保存什么 |
| --- | --- |
| 任务与数据协议 | 类别定义、标签来源、采样率/单位/传感器、原始文件与组编号。 |
| 输入处理 | 窗口长度与步长、滤波、标准化统计量、缺失值和异常值处理。 |
| 计算结构 | 每层输入输出形状、可训练参数、输出类别顺序、结构配置。 |
| 学习目标 | 分类/重构等损失公式与权重；优化器、学习率、batch、轮数。 |
| 选择与评价 | 划分清单、验证规则、最佳checkpoint依据、锁定的测试指标。 |
| 推理包 | 结构定义、权重、预处理、标签映射；单样本或批次推理入口。 |
| 可复现信息 | 代码版本、依赖版本、种子、运行命令、日志和硬件说明。 |
| 适用边界 | 已测工况、失败案例；若要部署，增加拒识、延迟、漂移监测。 |

解释模块不是每个分类器运行的必要部件；如果你的研究声称“模型依据合理”或“实现可解释诊断”，就必须提供解释对象、计算设置、对照实验和失败例子。

> 最小完整交付：给定新原始信号，别人能用同样处理方式加载你的模型，得到与类别映射一致的输出，并知道这个结果在哪些条件下验证过。


## 20  修改模型时检查什么

先定位失败，再做一次可解释的改变。

例如：低信噪比下内圈故障召回率下降。你的假设可以是“局部滤波长度不足以捕获重复冲击”。先检查数据与窗口覆盖，再比较卷积核或感受野；不要同时堆注意力、超网络和新损失。

| 检查项 | 具体问题 |
| --- | --- |
| 张量接口 | 长度、通道、batch维度是否一致？拼接和残差相加是否兼容？ |
| 物理单位 | 归一化后幅值还有原单位吗？频率参数是Hz还是归一化频率？ |
| 梯度与数值 | 可学习滤波是否被detach？有无NaN、梯度消失或爆炸？ |
| 目标与代价 | 新损失降低是否损害分类？参数量、显存、推理时间增加多少？ |
| 公平比较 | 使用同一独立划分、训练预算、模型选择规则和评价样本吗？ |
| 消融与稳定性 | 只改模块A、只改B、A+B；多个种子和独立测试组是否一致？ |
| 解释有效性 | 频带解释能否经遮蔽、随机对照和物理规律支持？ |

### 每次修改保留一张实验卡

问题 → 假设 → 唯一改变 → 预期观测 → 反例条件 → 验证指标 → 结果 → 结论。若提高很小或跨组不稳定，应保留“不支持改进”的结论。测试集一旦用于反复决策，就需要新的最终验证数据。

> 不必第一天掌握FNO和超网络。先能解释一段信号、完成无泄漏的CNN基线，再用明确问题决定下一步学什么。
