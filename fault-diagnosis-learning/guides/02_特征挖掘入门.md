
## 特征挖掘入门

适合尚未建立模型的初学者；与深度学习手册配套使用。

“特征挖掘”没有单一固定算法。在本手册中，它指从原始信号或模型中寻找能描述状态、区分类别并接受验证的信息。先区分你最终想得到的是一个数、一组表示、一张解释图，还是一段提取后的波形。

| 你在做什么 | 典型输出 | 推荐先学 |
| --- | --- | --- |
| 人工特征提取 | 均方根、峰值、频带能量等数值。 | 采样、统计量、FFT。 |
| 时频/模态分析 | 时频图、包络谱、候选分量。 | 滤波、调制、Hilbert、小波。 |
| 特征筛选 | 少量更有用的特征。 | 相关性、冗余、交叉验证。 |
| 表示学习 | 模型中间层的向量或特征图。 | CNN、自动编码器。 |
| 模型解释 | 哪些输入/频带影响某次预测。 | 归因、遮蔽、基线、忠实性。 |

> 先回答“这个特征对什么任务有用”。能区分训练标签，不等于找到了故障机理；模型重视某个频率，也不等于该频率必然来自故障。

### 阅读顺序

第2–4页：信号与特征；第5页：筛选和降维；第6–8页：模型内部表示与解释；第9页：完整练习；第10页：学习路线与自测；第11–12页补分解参数与设备机理。末尾是参考文献，完整资源评估见配套Excel。

符号：x为一段信号，N为采样点数，fs为采样率，z为特征，f为模型。数值例子均为教学设定；本手册未复现文献性能。


## 01  第一个特征表怎么来

一行对应一个样本窗口，一列对应一个特征；同时保留原始来源。

从一段振动数组x中计算特征，就像给一段声音写几项简明描述：“整体有多强”“偶尔的尖峰有多突出”“能量在哪个频段”。特征计算通常不需要先训练深度模型。

| 特征 | 简化定义 | 有用之处与限制 |
| --- | --- | --- |
| 均值 | 所有采样点的平均 | 反映偏置；传感器直流漂移可能影响它。 |
| RMS 均方根 | sqrt(mean(x^2)) | 描述整体幅值；随负载/增益变，对大幅异常点敏感。 |
| 方差 | mean((x-均值)^2) | 描述离散程度；受异常值影响；此处用总体方差1/N。 |
| 峰峰值 | max(x) - min(x) | 对极值敏感；偶发干扰也会使它增加。 |
| 峭度 | mean((x-均值)^4) / 方差^2 | 描述尾部/尖峰；高峭度并非故障的充分条件。 |
| 峰值因子 | max(abs(x)) / RMS | 描述峰值相对整体强度；分母接近0要特殊处理。 |

### 第一次只做5–10个可解释的特征

每条记录保存：sample_id、group_id、设备、转速、负载、窗口起点、真实标签和各特征。先画各类分布，再观察同一类别在不同工况下是否变化。不要把sample_id或人为编码的文件名送入分类器。

> 峭度有Pearson与Fisher等约定：正态分布前者为3，后者为0。报告是否减3、是否做偏差校正，以及窗口长度。不同库的默认值不能盲目混用。

量纲：若x单位为m/s²，均值、RMS、峰峰值同单位，方差为(m/s²)²，峭度/峰值因子无量纲。乘2后RMS乘2、方差乘4、峭度不变；逐窗标准化会削弱幅值信息。


## 02  FFT、频谱和包络谱

先理解横轴与单位，再讨论哪个峰对应故障。[F01–F03]

采样率fs表示每秒测量多少次。N个采样点构成时长T=N/fs的窗口，DFT频点间距为fs/N。例：fs=12,000 Hz、N=1,200，时长0.1秒，频点间距10 Hz；是否能分开邻近谱峰还受窗函数和信噪比影响。

| 表示 | 它显示什么 | 适合问什么问题 |
| --- | --- | --- |
| 时域波形 | 数值随时间变化。 | 冲击何时发生、是否重复？ |
| 幅值谱/功率谱 | 各频率的幅值或功率。 | 旋转谐波、共振和频带能量在哪？ |
| 包络谱 | 振动幅值起伏的频率成分。 | 高频共振是否被低频重复冲击调制？ |
| 阶次谱 | 频率除以转频后的无量纲阶次。 | 转速变化时，成分是否跟随转速？ |

### 包络分析的直观过程

先选有依据的共振频带并滤波 → 计算解析信号 → 取幅值得到包络 → 对包络计算频谱。滤波带不能在最终测试集上反复挑到“最好看”；边缘瞬态要识别或裁除。

> 注意：零填充可以让频谱曲线更密，却不会增加原始观测信息。幅值谱、功率谱和PSD的单位/归一化不同；单边谱倍增与窗增益修正也要说明。

更高采样率不自动改善低频分辨率；更长观察时间通常提供更细频率区分，但可能混合变化中的工况。选择窗口要同时考虑最低关注频率和近似平稳条件。


## 03  时频分析与分量提取

信号变化很快时，只看整段FFT会丢失“什么时候发生”的信息。

| 方法 | 基本思想 | 应注意的选择 |
| --- | --- | --- |
| STFT 短时傅里叶 | 在移动短窗中计算FFT。 | 长窗利于频率分辨，短窗利于时间定位；记录窗、步长。 |
| CWT 连续小波 | 用不同尺度的波形模板匹配信号。 | 尺度到Hz的换算、小波类型和边界效应。 |
| VMD 变分模态分解 | 把信号拆成若干有限带宽模态。 | 模态数K与惩罚系数；检查不同初始化和噪声。 |
| 盲解卷积 | 学习滤波器，增强被传递路径模糊的冲击。 | 目标函数可能偏好孤立大冲击；需周期性和物理验证。 |
| 循环谱分析 | 联合观察载频与循环/调制频率。 | 计算量、平滑和频率分辨率；先学调制与包络。 |

### “提取特征”和“提取分量”不一样

从信号得到一个RMS数值，是描述；从信号得到一段滤波波形，是变换或候选分量提取。要声称分离出物理源，还需要已知源模拟、独立传感器、故障干预或其他外部证据。[F06；融合册C07,C08]

> VMD的第2个模态不是天然的“故障模态”。不能只根据最高峭度挑出它，就声称剩余部分全是噪声。重复冲击、频率/阶次和对照实验应一起检查。

对不同方法比较时，使用相同信号、同一幅值/频率单位和一致的显示范围。为了“更清楚”随意改变色标，会造成视觉上的虚假提升。


## 04  选特征与降维

先划分独立数据，再在训练部分学习筛选规则。[F04,F05,F13,F14]

| 方法 | 怎样做 | 优缺点 |
| --- | --- | --- |
| 过滤式 filter | 按方差、相关系数、统计检验或互信息评分。 | 快；单特征评分可能漏掉协同作用。 |
| 包裹式 wrapper | 反复训练模型，比较特征子集。 | 贴近任务但计算贵；容易对验证集过拟合。 |
| 嵌入式 embedded | 把选择包含在模型训练中，如L1或树模型。 | 与模型关联；相关特征可能被任意分摊或替代。 |
| 降维 projection | 把原特征组合成较少的新坐标，如PCA。 | 压缩不等于挑原列；新坐标可能难做物理解读。 |

### 正确的小流程

原始记录分组 → 训练折提取特征 → 在训练折拟合缺失值处理、标准化和选择器 → 同样变换验证折 → 选超参数 → 最终独立测试。交叉验证中，每一折都重做拟合过程；可用Pipeline帮助封装。

### 两类常见误读

1. 一列特征与标签相关，可能只是转速或负载与故障标签绑定。应做同工况比较和跨工况验证。2. t-SNE/UMAP二维图分得很开，不等于分类器泛化好；投影参数、随机种子和采样都会影响图。不要用测试图反复选择模型。

> 选择多少个特征也是超参数。用训练/验证数据确定；测试集只能评价最终选好的方案。报告选择稳定性，比只展示一次最优名单更有价值。


## 05  模型内部的特征是什么

把网络拆成“编码器”和“任务头”来理解。

一个诊断网络可写成：z=g(x)，预测=h(z)。g把波形变成中间表示z，h把表示变成类别分数。z可能是一维向量，也可能是“通道×时间”特征图；每个元素通常不能直接对应一个已知物理量。

| 观察对象 | 可以做的分析 | 不能直接推出 |
| --- | --- | --- |
| 卷积核 | 看波形和频率响应；参数化核可看中心频率。 | 该层后面的所有决策都符合物理。 |
| 通道激活 | 看哪个窗口/类别触发响应。 | 响应大就一定对输出贡献大。 |
| 隐藏向量z | 比较类别、工况分布；做简单线性探测。 | 二维可视化分开就等于真正泛化。 |
| 自动编码器重构 | 比较原始与重构信号和残差。 | 低重构误差一定表示健康。 |
| 原型 | 找代表某类的模式并与真实样本比较。 | 生成的原型一定是可实现的物理状态。 |

### 先做一个小分析

冻结模型，分别抽取正常、故障、不同转速的中间向量。检查同类是否仍按工况分团；若工况比故障影响更大，提示模型可能利用了捷径。再用独立分组验证，而不是凭图立即下结论。

> “特征”是信息的表示，“解释”是对预测依据的说明。网络能学出有用表示，并不自动意味着每个通道可命名为某种故障频率。


## 06  SHAP、IG与遮蔽怎么理解

先固定被解释的模型、样本和输出，再计算重要性。[F07–F09,F11,F12]

| 方法 | 直观做法 | 关键设置 |
| --- | --- | --- |
| 遮蔽 Occlusion | 替换某时间片或频带，看预测变化。 | 替换值、片段宽度、相位与能量是否被意外改变。 |
| Integrated Gradients | 沿基线到真实输入的路径累计梯度。 | 基线、积分步数、目标输出；解释时仍需梯度。 |
| SHAP | 比较不同特征组合对输出的贡献。 | 背景集、特征依赖、masker、近似误差与计算量。 |
| Grad-CAM | 用目标梯度加权卷积层激活。 | 哪一层、目标类别、上采样；热图分辨率有限。 |

### 局部解释与全局解释

局部解释回答“这个样本为何这样预测”。全局解释可以汇总很多样本的归因，例如分组平均绝对贡献，但必须同时保留类别和工况差异。把正负贡献直接平均，可能互相抵消。

> 例：对“内圈故障”的logit做解释，正归因表示相对选定基线增加该logit；如果改成概率，贡献尺度与含义会变化。始终写明解释的是logit、概率还是损失。

model.eval()可以固定Dropout/BatchNorm的行为，但IG等方法仍需计算输入梯度，不能把整个解释过程放进no_grad。冻结参数不等于切断输入梯度。


## 07  怎样验证挖到的特征

热图漂亮只是起点；需要与模型和信号两个方面都核对。[F10；融合册C10]

| 证据 | 实验怎么做 | 支持的结论 |
| --- | --- | --- |
| 预测有效 | 独立设备/记录测试，报告各类召回率。 | 模型能否在规定数据范围内诊断。 |
| 归因忠实 | 删除重要片段，与同宽/同能量随机片段比较。 | 所标信息是否影响当前模型。 |
| 方法敏感 | 随机化模型参数、随机化标签重训后再解释。 | 解释是否真正依赖学到的规律。 |
| 结果稳定 | 换种子、样本和小幅无害扰动，比较排名。 | 结论是否过度依赖一次偶然结果。 |
| 物理一致 | 比对故障频率、谐波、侧频和转速关系。 | 解释与机理是否相容。 |
| 外部验证 | 更换设备或进行可控故障/健康对照。 | 排除部分替代解释，扩大可信范围。 |

删除频带会改变输入分布，分数下降可能是破坏了信号整体结构。因此还应比较合理替换、随机带、能量匹配带，并检查处理后波形是否仍像可能出现的测量。

> “解释支持模型依赖某频段”是恰当的表述；“解释证明该频段由故障导致且模型永远正确”超出了证据。若基线不合理，归因数值再精细也可能误导。


## 08  可以照着做的第一项练习

目标：从波形到特征表，再到一个可信的简单分类基线。

| 步骤 | 你需要产出什么 | 完成标准 |
| --- | --- | --- |
| 1 读一条公开记录 | 时域图、采样率、单位、设备和标签信息。 | 能从样本点数算出时间长度。 |
| 2 建分组清单 | 每个原始记录归属训练/验证/测试。 | 相同独立试验不跨集合。 |
| 3 计算基础特征 | RMS、峭度、峰值因子、少量预定频带能量。 | 每列有公式、单位和参数说明。 |
| 4 检查混杂 | 各特征按类别与转速/负载分别画分布。 | 知道至少一种与故障无关的变化来源。 |
| 5 训练简单模型 | 标准化+逻辑回归或SVM；再看随机森林。 | 所有拟合在训练内，验证选参。 |
| 6 最终测试 | 混淆矩阵、macro-F1、分组结果和错例。 | 说明独立样本量与适用范围。 |
| 7 解释特征 | 置换重要性或SHAP，与分组物理观察比较。 | 不把相关性写成因果性。 |

### 如果没有真实数据

先合成一个正弦波和一个周期冲击信号，比较特征变化。模拟信号的组成已知，适合验证程序；但不代表现场分布，不能用模拟高分代替真实验证。再使用CWRU或Paderborn练习完整数据协议。

> 交付物：数据字典、划分清单、特征配置、可重运行脚本、模型、评价表、解释图和限制说明。


## 09  学什么、学到什么程度

按过关标准推进，不以读了多少论文衡量进度。

| 阶段 | 知识 | 过关任务 |
| --- | --- | --- |
| 基础 | Python数组、绘图、统计量。 | 独立生成时域图和RMS表。 |
| 频域 | 采样、FFT、窗函数、滤波。 | 画正确Hz坐标并解释频率间距。 |
| 机理 | 转频、调制、包络、阶次。 | 分清共振载频与重复冲击频率。 |
| 筛选 | 相关性、冗余、Pipeline、分组验证。 | 在训练折内选择特征，不碰测试标签。 |
| 解释 | 归因、基线、目标输出、反证检验。 | 给一张解释图配三个对照与一个限制。 |
| 研究 | 跨工况、稳定性、物理验证。 | 写出一个可被否定的假设及验证计划。 |

### 五个自测问题

① RMS增大一定意味着故障吗？② 零填充能增加真实分辨能力吗？③ PCA和特征选择一样吗？④ SHAP正值意味着物理上导致故障吗？⑤ 最高峭度模态就是故障源吗？

### 参考答案

① 不一定，负载/增益也会改变RMS。② 不能，只是更密的频谱取样。③ 不一样，PCA重新组合变量。④ 不意味着，只表示相对背景对指定模型输出的贡献。⑤ 不一定，噪声或单次冲击也可能有很高峭度。

推荐顺序：F01、F02 → F03、F04 → F13、F11 → F08、F12、F10 → F05、F06、F07。高级分解和解释方法等基础流程完成后再做。


## 10  分解与冲击增强怎么选

先学滤波、包络和周期，再尝试高级分解；不为算法名字叠加处理。

| 方法与作用 | 关键参数 | 怎样判断与局限 |
| --- | --- | --- |
| VMD：分出有限带宽模态 | 模态数K、惩罚系数、初始化、停止容差。 | 比较中心频率、重构残差和跨工况稳定性；模态不天然等于故障源。 |
| FMD：以周期冲击特征为目标的自适应滤波分解 | 滤波器长度、初始频带数、保留模态数、迭代次数。 | 检查模态包络的重复周期和谐波；偶发冲击可能干扰周期估计，参数按实现核对。 |
| MCKD：最大相关峭度盲解卷积 | 预期周期T（点）、移位阶数M、滤波器长度、迭代次数。 | 适于增强重复冲击；周期失配或转速变化会失效，不能把大峭度当因果证据。 |
| MOMEDA：目标冲击列驱动的滤波求解 | 目标周期/搜索区间、目标窗、滤波器长度。 | 给定目标时滤波求解非迭代；周期搜索仍需设计，伪周期和边缘瞬态须对照。 |

例：采样率12,000 Hz、假设冲击重复频率100 Hz，初始周期约120点；这是教学设定。先用已知真值模拟信号扰动周期和滤波长度，再在独立真实记录检验，不在测试集挑最好看的参数。

> 比较原信号、普通带通、候选方法；同时看重构残差、故障频率附近成分、无关带及分类指标。只提升峭度或只得到更清楚的图，还不足以证明诊断改善。

原始方法与作者入口见科研论文库F07(VMD)、F08(FMD)、F04(MCKD)、F05(MOMEDA)，编号仅在新库有效：[科研论文目录](../research-papers/README.md)。本页为原理导读，未执行这些算法。


## 11  频谱与机理必须对齐

先排除处理伪影，再将特征同具体设备的激励和传递路径对照。

### 窗函数、谱泄漏与边带

DFT把有限窗口视为周期重复。截断点不连续会让能量扩散到其他频点，称谱泄漏。Hann等窗能降低旁瓣，却加宽主瓣；幅值比较需做窗增益修正。记录窗型、长度与归一化，零填充不代替真实分辨率。

谐波在基频的整数倍附近；调制可形成载频两侧间隔为调制频率的边带。先看是否随转速变化，再判断是故障、正常旋转还是电气干扰。单个谱峰无法独立确诊。

| 对象 | 可对照的机理 | 使用条件与限制 |
| --- | --- | --- |
| 滚动轴承 | 内圈/外圈/滚动体/保持架特征频率、谐波及调制边带。 | 需几何、转速、接触角；滑移与负载会致偏移，不能把理论值视为每次精确真值。 |
| 柴油机工作事件 | 燃烧、气门与喷油事件相对曲轴角的位置。 | 需同步转速/曲轴角与缸序；四冲程工作循环为720°，区分正常工作冲击和异常。 |
| 喷油器异常 | 喷油事件附近振动、缸压或供油变化的特征。 | 结合故障类型、程度及独立标签；不能套用轴承故障频率。 |

### 变转速时何时做阶次分析

阶次=频率/转频。变转速记录通常需要可靠转速或角度估计，并按等角度重采样；检查同步、插值和抗混叠。直接将整段FFT除以平均转频并不能消除转速涂抹。没有可靠转速时，应说明阶次结论的不确定性。
